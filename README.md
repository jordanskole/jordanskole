# Hey, I'm Jordan

I build data infrastructure — the kind that lives closer to the user than most people expect.

For the last 8 years at [Autobooks](https://autobooks.app) I've been the hands-on architect behind a browser-native analytics platform for financial institutions: a full pipeline from legacy bank cores (Jack Henry, FIS, Q2) through Arrow IPC → Parquet → DuckDB-WASM, rendering live financial data entirely client-side with no backend query layer. It's in production, it's fast, and it does things most people assume require a server.

More recently I bolted a Claude-powered AI assistant onto the same stack — tool calling, DuckDB queries, Observable Plot chart generation, internal doc retrieval — all running in the browser via Azure AI Foundry.
